# MedPlant Master – SEE Edition

A lightweight browser game for Nepal SEE Class 10 students to learn medicinal plants, their scientific names, and treatment features.

## Features

- 🔥 **Quick Match Mode** with 30-second timer and streak bonus
- 💀 **Survival Mode** with 3 lives and score multipliers
- 🧠 **Memory Challenge** with flash recall
- 📝 **SEE Exam Simulation** (MCQ + matching + short answers)
- 🖼 **Image Identification (hint-based)**
- ✅ **Weakness Tracker** with adaptive revision weighting
- 🌱 **XP + Levels** progression
- 🏆 **Local leaderboard** and daily challenge

## Run locally

Open `index.html` directly in a browser, or serve this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
